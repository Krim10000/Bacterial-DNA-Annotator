# Citas y licencias de etiquetas

## Gene Ontology

- Ontología: `go-basic.obo`, `data-version: releases/2026-07-26`.
- Cita: Ashburner M. et al., *Nature Genetics* 2000;25:25-29.
- Recurso: The Gene Ontology Consortium, *Nucleic Acids Research*
  2021;49:D325-D334.
- Licencia: CC BY 4.0.
- URL: https://geneontology.org/

## GOA / UniProt

- Anotaciones GO: `ECOLI-uniprot.gaf.gz`, `ECOLI-mod.gaf.gz`,
  `BACSU-uniprot.gaf.gz`.
- Cita: The UniProt Consortium, *Nucleic Acids Research* 2023;51:D523-D531.
- Licencia: CC BY 4.0.
- URL: https://www.uniprot.org/

## KEGG

- Uso: `gene→KO`, `gene→pathway`, nombres de rutas.
- Cita: Kanehisa M., Goto S., *Nucleic Acids Research* 2000;28:27-30.
- Licencia: académica/no comercial; no se redistribuye en el repositorio.
- URL: https://www.kegg.jp/

## Rhea / EC

- Rhea: Bansal P. et al., *Nucleic Acids Research* 2022;50:D693-D700.
- EC: IUBMB Enzyme Nomenclature.
- Los archivos `rhea2go.tsv`, `rhea2ec.tsv`, `rhea2kegg_reaction.tsv` se
  usan localmente.

## Regla

Si una etiqueta no tiene fuente/licencia verificada, no se presenta como
gold; se marca como hipótesis o `no_data`.
