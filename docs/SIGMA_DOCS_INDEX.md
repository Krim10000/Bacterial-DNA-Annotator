3. `SIGMA_INVENTORY.md` — inventario por especie.
4. `SIGMA_KMER_CALIBRATOR.md` — calibrador k-mer.

## Regla

Si dos documentos se contradicen:

```text
SIGMA_SPEC.md gana.
Si el dato es experimental, SIGMA_STRATEGIES.md.
Si es gold/procedencia, SIGMA_GOLD.md.
Si es literatura, literature/README.md.
```
